# My portfolio

My name is Elyes Zguem and this is my portfolio running on a recreation of the PlayStation 2 system menu: the startup scene, the main menu orbs, the memory card Browser (where the projects live) and System Configuration.

It’s a static site, so there’s no build step, you just open index.html in any web server. The site says everything in content.js.

Controls: arrows, Enter (✕), Esc (○), T (△), Q (□), M (mute). Mouse and touch also work.

The rendering is based on the reverse-engineered OSDSYS ROM in [aap/osdbits](https://github.com/aap/osdbits).
